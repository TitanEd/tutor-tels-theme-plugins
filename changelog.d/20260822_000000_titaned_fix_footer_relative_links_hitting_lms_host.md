- [BugFix] Shared marketing header (`TelsHeader`) and footer (`IndigoFooter`): Home/Courses/About/Contact/Privacy/Terms links were built as bare root-relative paths (`/privacy`, `/about`, …), which only work if the public MFE is mounted at the site root. Tutor's default MFE routing actually serves it at `${MFE_HOST}/public`, so these links 404'd — Privacy and Terms were the most visible since they're only reachable from the footer, with no header equivalent. `INDIGO_HOME_URL`/`COURSES_URL`/`ABOUT_URL`/`CONTACT_URL` now default to `/public/...`, and the footer resolves its own relative links against `INDIGO_HOME_URL` the same way the header already did. Override `INDIGO_HOME_URL` via Tutor config if your deployment mounts the public MFE somewhere else.
