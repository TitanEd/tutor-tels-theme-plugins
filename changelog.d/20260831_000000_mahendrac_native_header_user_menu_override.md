All new copy goes through `defineMessages`/`useIntl`, and dropdown item labels intentionally reuse `@edx/frontend-component-header`'s own `account.user.menu.*` translation ids so every locale it already ships stays translated with no extra work. `TelsHeader.jsx`/`HeaderControls.jsx`/`LanguageMenu.jsx`/`ToggleThemeButton.jsx` are left on disk but no longer wired into any MFE.
